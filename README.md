# Personal Finance Analyzer

A simple Python application for analyzing personal expenses.

## Features

- Reads expenses from CSV files
- Calculates total expenses
- Groups expenses by category
- Calculates category percentages
- Sorts categories by spending

## Technologies

- Python 3
- CSV
- Collections
- pathlib

## How to run

1. Clone the repository
2. Create a virtual environment
3. Install dependencies if needed
4. Run:

python main.py
